# Sequel Decision Framework

## After Day 7: Identify Top 3 Performers
Rank all 20 videos by 7-day view count and engagement rate.

## Eligibility for Sequel
A video qualifies for a sequel if it:
- Exceeds channel median view count at day 7
- Has average percentage viewed > channel median + 5%
- Has engagement rate (likes + comments / views) > channel baseline

## Sequel Strategy
- **Same premise family**: Use the same core idea (e.g., "alien meets human") but with different details, characters, or scenarios
- **NOT a copy**: Different script, different visual beats, different outcome
- **Production timeline**: Days 25–27, publish days 28–29

## Example
- **Original (MF-001)**: "Last Signal" — lone astronaut sends final message
- **Sequel (SEQUEL-MF-001)**: "First Signal" — astronaut receives unexpected response
