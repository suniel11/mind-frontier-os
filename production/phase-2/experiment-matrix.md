# Phase 2 Experiment Matrix

## Single-Variable Testing

Each row = one published short with ONE experimental change from the previous upload.

### Variables (rotate through)
1. **Hook timing**: intro 0–2s vs 2–4s
2. **Title format**: imperative (Do X) vs declarative (This is X)
3. **Pillar mix**: 40% Choice, 30% Identity, 30% Survival vs even split
4. **Duration**: target 4–5min vs 6–8min
5. **Visual palette**: cool blues vs warm amber emphasis
6. **Voiceover pace**: slow deliberate vs natural conversational

### Tracking
- Record the variable changed for each day
- Measure: 24h views, avg % viewed, engagement rate
- Identify which variables correlate with higher retention
