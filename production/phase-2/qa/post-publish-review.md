# Post-Publish Review Protocol

## 24-Hour Window
1. Check analytics: views, completion %, engagement
2. Read first 20 comments for tone and comprehension
3. Record in phase-2-scorecard.csv

## 72-Hour Window
1. Re-check views, completion %, subscriber gain
2. Identify if video is trending upward or plateauing
3. Note any anomalies

## 7-Day Window
1. Final metric snapshot
2. Compare to channel median from days 1–10
3. Determine if video qualifies for sequel (top 3 performers)
4. Update overall pillar performance tracker
