# Pre-Publish Checklist

## Script
- [ ] Factual verification complete (if factual video)
- [ ] No grammar/spelling errors
- [ ] Consistent voice and tone per Brand Bible
- [ ] Matches content pillar intent

## Visual Assets
- [ ] All FLUX images generated and reviewed
- [ ] No visual continuity breaks
- [ ] Palette matches visual style guide
- [ ] Text/graphics are readable

## Audio
- [ ] Voiceover audio normalized to -16 LUFS
- [ ] No background noise
- [ ] Pacing matches visual beats
- [ ] Music sync is correct

## Metadata
- [ ] Title is CTR-tested formula
- [ ] Description includes hook
- [ ] Tags match topic database
- [ ] Thumbnail is generated and scored

## Final
- [ ] Video rendered at 1080p H.264
- [ ] Duration is within target range
- [ ] Upload preview played back correctly
