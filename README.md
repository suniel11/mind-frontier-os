# Mind Frontier OS

A comprehensive operating system for Mind Frontier sci-fi video production. This repository contains all operational procedures, brand guidelines, analytics, and creative assets needed to produce consistent, data-driven short-form content.

## 📋 What's Inside

- **docs/** — Nine "Bibles" covering brand, production, editorial, growth strategy, competitive intelligence, topics, prompts, video reviews, and monthly reports
- **data/** — Structured data: competitor tracking, analytics, formulas for titles/hooks
- **assets/** — Logos, color palettes, fonts, templates
- **research/** — Industry research, audience insights, trend analysis
- **templates/** — Reusable templates for scripts, thumbnails, descriptions

## 🚀 Quick Start

1. **Read the Bibles** — Start with `docs/01-brand-bible/` to understand the vision
2. **Review Analytics** — Check `docs/09-monthly-reports/` for latest performance data
3. **Create Content** — Use templates and prompts from `docs/07-prompt-library/`
4. **Track Results** — Log every video in `data/analytics/`

## 📊 Core Principle

**No changes without evidence.**

Every decision must be backed by:
- Quantitative data (YouTube Analytics, A/B tests)
- Qualitative feedback (comments, audience polls)
- Market intelligence (competitor analysis, trends)
- Production metrics (speed, cost, quality)

See `DECISION_RULE.md` in each Bible for enforcement.
