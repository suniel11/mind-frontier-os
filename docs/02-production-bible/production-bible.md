# Production Bible - Mind Frontier

## Pipeline
1. Script (Claude/Groq)
2. Voiceover (Google TTS)
3. Images (FLUX via Replicate)
4. Video (FFmpeg)
5. Upload (YouTube)

## Quality Standards
- **Video:** 1080p, 30fps, H.264, 5-8 Mbps
- **Audio:** AAC, 128kbps, 48kHz, -16 LUFS
- **Duration:** 3-10 minutes

## Budget
- Monthly Cap: $50
- Per Video: ~$5-10
- Cost Tracking: Weekly review

## File Naming
